# 📊 Corporate Data Analyzer

A Python-based data analytics tool designed to simplify data processing, aggregation, and visualization for corporate datasets.

The application allows users to upload Excel or CSV files and instantly generate analytical reports and charts to gain insights from raw data.

---

## 🚀 Features

- 📂 **Data Import**
  - Load CSV and Excel files easily.
  - Automatic dataset detection.

- 📊 **Data Analysis**
  - Group data by categories.
  - Calculate statistics such as:
    - Sum
    - Average
    - Median
    - Count

- 📈 **Data Visualization**
  - Generate charts instantly:
    - Bar Chart
    - Column Chart
    - Pie Chart
    - Line Chart

- 📑 **Report Generation**
  - Export charts and processed reports for presentations.

- ⚡ **Fast Processing**
  - Analyze large datasets quickly using Python libraries.

---

## 🛠 Tech Stack

- Python
- Pandas
- Matplotlib / Plotly
- Tkinter / GUI Interface
- OpenPyXL
